## Lagunas del Codex (no se rellenan)

- **4:8–18**: el Codex pasa de 4:7 a 4:19 (el texto enlaza «…a todos los que
  practican la justicia, el Señor les dará buen consejo»).
- **9:3**: no hay versículo 9:3 (pasa de 9:2 a 9:4).
- **13:8–10**: el Codex pasa de 13:7 a 13:11.
- **14:8**: no hay versículo 14:8.

## Puntos que conviene mirar primero

- **11:4**: el Codex escribe ‹κϲ› (abreviatura sagrada de «Señor») donde otros
  manuscritos griegos de Tobit hablan del perro. Se traduce «el Señor» y se explica.
- **14:15**: αχιαχαροϲ, rey de Media, no es Ajicar sino el rey medo que tomó
  Nínive (Ciáxares); se escribe **Aquiácaro** para distinguirlo.
- **ἀδελφή**: «hermana» cuando es trato de cariño o la fórmula del contrato
  (5:22, 7:12, 7:15, 8:4, 8:7, 8:21, 10:6, 10:13); «pariente» cuando describe
  parentesco (6:19, 7:6, 7:9).
- **ἐξομολογέομαι**: «dar gracias» (11:16; 12–14).
- Nombres nuevos: Edna, Azarías, Ananías, Semelio, Natán, Rages, Caserín,
  Nabad/Nadab (el Codex usa las dos formas: 11:19 y 14:10), Nahúm.
